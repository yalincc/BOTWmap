# 旷野之息 · 互动地图（简体中文多图层版）

《塞尔达传说：旷野之息》简体中文互动地图，支持多图层同显、收集进度追踪、实时角色导航。

## 直接使用

用浏览器打开 **`app/index.html`** 即可，无需服务器、无需联网（地图瓦片、图标与数据全部本地）。

> 完成进度、自定义标记、图层选择自动保存在浏览器本地存储中，关页不丢。

在线版：https://botw.yalin.site/

## 实时角色导航（可选）

配合 **xnavi**（Wails GUI 版，支持 Cemu / Ryujinx / Eden 三平台），在线地图可实时显示你在游戏里的位置：

1. 启动 Cemu / Ryujinx / Eden 并进入游戏
2. 双击 `xnavi.exe`，点"开始定位"
3. 浏览器打开在线地图，右下角出现实时坐标胶囊

- **四级秒锁**：已知偏移 → User Heap 定向扫描 → 扩大窗初筛 → 全量兜底，Eden 首次定位约 1 秒
- **三平台自动识别**：Cemu（大端）/ Ryujinx（小端）/ Eden（Yuzu fork）无需手选
- **存档联动**：每 2 秒探测存档变化，游戏保存后 ≤2 秒网页进度自动刷新
- **设置持久化**：模拟器路径、存档路径自动记住
- **自动更新**：启动时检查新版本
- 仅读内存，不注入，不修改游戏
- 更多细节见 `xnavi/` 和 `xnavi-gui/`

## 核心功能

| 功能 | 说明 |
|---|---|
| 多图层同显 | 标注层可任意勾选组合，一键全选 / 清空（联动装备 / 宝箱 / 任务 / 营地所有模块） |
| 分组勾选 | 探索收集 / 设施地点 / 敌人 / 任务 四组，每组可单独全选；装备 / 宝箱 / 营地 / 材料为独立图层模块 |
| 高清瓦片 | 7 级动态瓦片按需加载，最大 1:1 像素仍清晰，拖动缩放流畅 |
| 简体中文 | 全部标注点中文命名，附英文原名 |
| 点位详情 | 点击任意标注弹出详情卡：中文名 / 类别 / 区域 / 塔域 / 游戏坐标 / 位置提示 |
| 搜索 | 按中文 / 英文 / 区域 / 塔名搜索，回车直达并居中放大（含任务、装备、材料） |
| 材料追踪 | 74 种材料 / 13524 个采集点，独立 Tab + 材料专用搜索，按昆虫 / 植物 / 矿石 / 生物等类别勾选 |
| 营地刷点 | 555 个血月刷新营地（精选 54），一图标=一据点，标注掉落武器，回答"去哪刷什么武器" |
| 任务追踪（V1.6.0） | 官方三档任务「主线挑战 16 / 支线任务 89 / 神庙挑战 42」全部 147 项，地图标注任务点；完成状态双源：上传存档自动同步（权威）+ 手动标记兜底，点击任务点查看描述 / 流程 / 奖励 |
| 装备图鉴（V1.6.0） | 武器 90（单手剑 / 双手剑 / 长枪 / 弓 / 盾）+ 防具 31（头 / 衣 / 裤），收录宝箱与任务奖励来源；地图标注获取点（宝箱位置），点装备 / 搜索命中查看属性与获取点，可逐个定位；大师模式点位预留 |
| 收集追踪 | 标记"已完成"后点位半透明打勾，统计面板实时显示完成度（神庙、塔、神兽、克洛格、回忆、宝箱、任务）；可上传 Switch / Wii U·Cemu 存档（文件名均为 `game_data.sav`，自动识别端序）同步进度 |
| 距离测量 | 地图打点测量游戏内距离（米 / 公里） |
| 自定义标记 | 在地图上添加带名称和颜色的个人标记 |
| 分享链接 | 生成包含当前图层 + 视图位置的链接，发给别人打开即同款画面 |
| 坐标读数 | 鼠标悬停实时显示游戏 X / Z 坐标 |
| 克洛格轨迹 | 97 个追花/赛跑谜题完整路线，黄色折线，放大到区域级别自动显示（跟随「克洛格」图层勾选） |
| 敌人分级 | 强力怪固定 28px 图标；小怪按缩放分级：省区级 7px 色点 / 地区级 28px 图标 / 详查级 36px 图标 |
| 龙飞行轨迹 | 三龙（费罗龙/奥尔龙/聂尔龙）路线平滑曲线，颜色对应元素（黄/红/蓝），起点龙图标 + 终点圆点，在设置面板开关，任意缩放显示 |

## 数据内容

### 探索收集与设施（6521 个标注点）

- 神庙 137（含 20 座 DLC「英杰之诗」神庙）、希卡塔 15、神兽 4
- 克洛格果实 900（带位置提示）、照片回忆 13、宝箱 1315（含物品名）
- 强力怪：莱尼尔 23、西诺克斯 40、岩石巨人 40、莫尔德拉吉克 4、守护者 148
- 小怪（官方图鉴图标）：波克布林 1082、莫力布林 271、蜥蜴战士 679、蝙蝠 371、丘丘 458、八爪怪 227、魔法师 53、依盖队 24、小岩石人 272
- 敌人支持大师模式分层（tier 0~3 + hardmode 数据已入库，按游戏进度显示对应阶段）
- 龙（特殊怪，飞行轨迹）：费罗龙（黄）/ 奥尔龙（红）/ 聂尔龙（蓝）
- 设施：村庄 10、驿站 15、旅馆 10、商店 / 防具 / 染坊 / 珠宝、古代研究所、大精灵之泉 5、女神像 14、锅子 112、木筏 46、据点 6

### 任务与装备（V1.6.0）

- 官方三档任务：主线挑战 16、支线任务 89、神庙挑战 42，共 147 项
- 装备：武器 90（单手剑 / 双手剑 / 长枪 / 弓 / 盾）、防具 31（头 / 衣 / 裤），宝箱 + 任务奖励来源

### 材料采集（独立图层，74 种 / 13524 个刷点）

- 昆虫、植物、矿石、生物等 74 种可采集物，数据源自 romfs `map_units(1.6.0)` 官方简中 MSBT
- 仅 MainField 地表固定刷点；暖暖鳟鱼 / 潜行鳟鱼 / 耐火凤蝶为动态生成，无固定点
- 独立 Tab 与搜索框，按类别勾选显示

### 营地刷点（独立图层，555 个营地）

- 血月刷新的怪物营地，hot 精选 54 + all 全量 555
- 每个营地标注常驻怪物与掉落武器（含武器等级推导），点击查看营地掉落段
- 莱尼尔营地并入莱尼尔标记，不重复画营地图标

## 已知限制

- 部分神庙试炼信息缺失（祝福型神庙等）
- 区域为按官方区域中心点的近似归属，个别边界点可能偏差
- 宝箱中少量冷门物品保留英文名（如大师模式专属变体）
