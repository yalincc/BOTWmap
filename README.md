# 旷野之息 · 互动地图（简体中文多图层版）

《塞尔达传说：旷野之息》简体中文互动地图，支持多图层同显、收集进度追踪、实时角色导航。

## 直接使用

用浏览器打开 **`app/index.html`** 即可，无需服务器、无需联网（地图瓦片、图标与数据全部本地）。

> 完成进度、自定义标记、图层选择自动保存在浏览器本地存储中，关页不丢。

在线版：https://botw.yalin.site/

> **部署方式**：腾讯云 EdgeOne Pages 关联 Gitee 仓库 `yalincc/botwmap`，push 到 `gitee/main` 即自动部署，输出目录 `app/`。改完代码只 push Gitee 即可（GitHub 为镜像备份，非部署源）。

## 实时角色导航（可选）

配合 `live-go/BotwNavi.exe`（单文件约 7MB，无需安装、无需 Python），在线地图可实时显示你在游戏里的位置：

1. 启动 Ryujinx 并进入游戏（读档）
2. 双击 `BotwNavi.exe`
3. 浏览器自动打开在线地图，右下角出现实时坐标胶囊（绿色 ● 玩家位置 · 目标距离）

- 首次定位约需几秒，之后每秒 10 次刷新
- 仅支持 Ryujinx 模拟器 + 旷野之息；首次打开若弹浏览器私有网络权限确认请允许
- 更多细节见 `live-go/README.md`

## 核心功能

| 功能 | 说明 |
|---|---|
| 多图层同显 | 28 类标注可任意勾选组合，一键全选 / 清空 |
| 分组勾选 | 探索收集 / 设施地点 / 敌人 / 任务 四组，每组可单独全选 |
| 高清瓦片 | 7 级动态瓦片按需加载，最大 1:1 像素仍清晰，拖动缩放流畅 |
| 简体中文 | 全部 3084 个标注点中文命名，附英文原名 |
| 点位详情 | 点击任意标注弹出详情卡：中文名 / 类别 / 区域 / 塔域 / 游戏坐标 / 位置提示 |
| 搜索 | 按中文 / 英文 / 区域 / 塔名搜索，回车直达并居中放大 |
| 收集追踪 | 标记"已完成"后点位半透明打勾，统计面板实时显示完成度（神庙、塔、神兽、克洛格、回忆、宝箱） |
| 距离测量 | 地图打点测量游戏内距离（米 / 公里） |
| 自定义标记 | 在地图上添加带名称和颜色的个人标记 |
| 分享链接 | 生成包含当前图层 + 视图位置的链接，发给别人打开即同款画面 |
| 坐标读数 | 鼠标悬停实时显示游戏 X / Z 坐标 |

## 数据内容（28 类，共 3084 点）

- 神庙 137（含 20 座 DLC「英杰之诗」神庙）、希卡塔 15、神兽 4
- 克洛格果实 900（带位置提示）、照片回忆 13、宝箱 1315（含物品名）
- 敌人：莱尼尔 23、西诺克斯 40、岩石巨人 40、莫尔德拉吉克 4、守护者 148
- 设施：村庄 10、驿站 15、旅馆 10、商店 / 防具 / 染坊 / 珠宝、古代研究所、大精灵之泉 5、女神像 14、锅子 112、木筏 46、据点 6
- 任务：主线 16、神庙挑战 42、支线 89、任务地点 33

## 已知限制

- 部分神庙试炼信息缺失（祝福型神庙等）
- 区域为按官方区域中心点的近似归属，个别边界点可能偏差
- 宝箱中少量冷门物品保留英文名（如大师模式专属变体）
