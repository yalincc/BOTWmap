# 旷野之息 · 互动地图（简体中文多图层版）

复刻自 [gamertw.com BOTW 地图](https://www.gamertw.com/zelda/botw-map) 与
[游侠 ali213 地图](https://zelda.ali213.net/)，取两者优点并加入自定义功能：

- **取自 ali213**：简体中文、游戏内图标、固定图标尺寸、坐标信息、神庙试炼/宝藏/任务信息、**瓦片动态加载**
- **取自 gamertw**：多图层可同时勾选显示、丰富类别（任务 / 回忆 / 克洛格 / 宝箱 / 敌人 / 设施）
- **新增功能**：完成度收集追踪、名称搜索、区域/塔域信息、距离测量、自定义标记、分享链接、统计面板

## 直接使用

用浏览器打开 **`app/index.html`** 即可，无需服务器、无需联网（地图瓦片、图标与数据全部本地）。

> 完成进度、自定义标记、图层选择自动保存在浏览器本地存储中，关页不丢。

## 瓦片引擎（性能优化）

地图采用与 [ali213](https://zelda.ali213.net/) 相同的**动态瓦片加载**方案，彻底解决大图卡顿：

- **分层瓦片**：全图 → 放大共 7 级分辨率（zoom1~7，与 ali213 一致），共 10096 张 **WebP 瓦片（41MB）**
- **按需加载**：只加载当前屏幕可见的瓦片，平移 / 放大时才加载新区域与新层级，内存仅保留视口附近（LRU 缓存上限 400 张，约 70MB，替代旧版 45MB 整图常驻 1.4GB）
- **放大有限制**：最大缩放到 1:1 像素（对应 ali213 maxZoom7），不做无意义放大
- **秒开**：冷启动约 0.8 秒（旧版需解码 45MB 整图），拖动缩放流畅

## 数据来源与坐标换算

- 标注数据：gamertw.com BOTW 地图（`source/gamertw_T_markers.json`，含坐标与英文名）
- 中文名称：gamertw 官方繁中词典（`source/gamertw_tc_en_dict.json`，862 条）经 OpenCC 转简体 + 官方简中修正
- 图标与神庙信息：ali213 地图（`source/ali213_coords.json`，30 类坐标全量 + ccontent 试炼/宝藏/任务）
- 地图底图：ali213 瓦片全量抓取（zoom1~7 共 10096 张）→ WebP 压缩后存 `app/assets/tiles/`（41MB，运行时按需加载）；
  原始 PNG 瓦片与拼接整图属构建产物，已清理（可用 `tools/fetch_tiles.py` / `fetch_tiles_low.py` 重抓、`tools/mosaic_tiles.py` 重拼）
- 坐标校验：15 座希卡塔坐标与游戏数据交叉验证，误差 < 1px；137 神庙与 ali213 完全一致
- 换算公式：gamertw 坐标 → 游戏坐标 `gameX = y/2, gameZ = -x/2` → 地图像素 `pxX = gameX*2 + 12000, pxY = gameZ*2 + 10000`（24000 系）


## 目录结构

```
app/                # 可直接打开的产品
  index.html
  css/style.css
  js/map.js         # Canvas 地图引擎（平移/缩放/渲染/命中/图标）
  js/ui.js          # 图层面板/搜索/卡片/统计/工具
  js/main.js        # 入口
  js/data.js        # 全部标注数据（生成产物，24000×20000 坐标系）
  assets/tiles/     # 瓦片 10096 张（zoom1~7，运行时按需加载）
  assets/icons/     # 游戏内图标 35 张（ali213）
source/             # 抓取的原始数据（gamertw 页面/词典、ali213 坐标，waypoint-data 为 git 克隆）
tools/              # 数据构建脚本
```

## 已知限制

- 神庙试炼信息覆盖 119/137（18 座 ali213 无试炼内容，如个别祝福型或信息缺失）
- 区域为按 8 大官方区域中心点的近似归属，个别边界点可能偏差
- 宝箱中少量冷门物品保留英文名（如 Master Mode 专属变体）
