# BOTWNavi-Eden · 旷野之息实时定位导航

《塞尔达传说：旷野之息》（BOTW）实时定位工具，在网页地图上显示你在游戏里的位置，走路跟随。支持 **Eden** 模拟器（Switch 版 BOTW）。

网页地图：<https://botw.yalin.site>

![platform](https://img.shields.io/badge/platform-Windows-blue) ![emulator](https://img.shields.io/badge/emulator-Eden-success)

---

## 功能

- **实时跟随**：只读模拟器内存，在网页地图上显示玩家坐标，随走路实时移动
- **扫描 + 记忆定位**：Eden 内存碎片化无固定锚点，靠存档锚点全量扫描定位；锁到后记忆绝对地址（known_botw.json），下次启动秒锁；失效自动重扫
- **坐标校准**：扫描失效时，输入游戏 HUD 显示的三轴坐标，全内存精确匹配秒锁（GUI 校准卡片）
- **自动重锁**：传送、读图、游戏重启都自动重新锁定，无需手动操作
- **存档进度看板**：自动读游戏存档，显示神庙/高塔/克洛格/回忆/英杰神兽进度
- **深色 GUI**：Wails 写的 Windows 桌面界面，状态一目了然
- **一键诊断**：出问题时点"导出诊断包"，把系统信息和日志打包发给开发者
- **只读内存**：不注入、不修改游戏、不联网上传任何数据

## 下载与使用

1. 从 [Releases](https://github.com/yalincc/BOTWmap/releases) 下载最新版 `BOTWNavi-Eden-vX.Y.Z.zip`
2. 解压到任意目录（路径不要有中文/空格更稳妥）
3. 先启动 Eden，进入游戏（站在海拉鲁大地上，别开菜单）
4. 双击 `BOTWNavi-Eden.exe`
5. 点 **▶ 开始定位**
6. 锁定成功后自动打开网页地图；首次使用需全量扫描（5-30 秒）；若一直扫不到，在游戏里站桩，用"坐标校准"输入 HUD 坐标秒锁
7. 在网页地图上就能看到自己的红点，跟着走就行

> 首次运行 Windows 可能弹防火墙提示，点允许——它只在本机 `127.0.0.1:8766` 起 HTTP 服务给网页读坐标，不对外暴露。

## 常见问题

**Q: 点开始后一直"等待模拟器进程"？**
A: 确认 Eden 已经启动并且游戏已经进到大地图（在主菜单里不行）。工具按进程名 `eden` 前缀探测，别把模拟器改名。

**Q: 一直"扫描中"不出坐标？**
A: 首次使用会全内存扫描，需要 5-30 秒。扫到后自动写入 known_botw.json，之后秒锁。长时间扫描不到请用「坐标校准」：游戏里站桩，把 HUD 显示的 X/Y/Z 输入校准卡片。

**Q: 网页地图看不到红点？**
A: 确认工具顶栏显示"坐标流同步中"，然后刷新网页 https://botw.yalin.site 。本地端口 8766 不能被别的程序占用（TOTK 的 TOTKNavi-Eden 也用 8766，勿同时开两个核心）。

**Q: 传送/读图后红点不动？**
A: 会自动重新锁定，几秒内恢复跟随，无需手动操作。

## 与 TOTK 版（TOTKNavi-Eden）的关系

两个程序同源（Eden 模拟器定位引擎），分属两个仓库独立发布：

| | BOTWNavi-Eden | TOTKNavi-Eden |
|---|---|---|
| 游戏 | 旷野之息 BOTW | 王国之泪 TOTK |
| 仓库 | yalincc/BOTWmap | yalincc/totkmap |
| 版本 tag | botwnavi-eden- | live-eden- |
| 端口 | 8766 | 8766（勿同时运行两个核心） |
| known 文件 | known_botw.json | known_addrs.json |

## 数据与隐私

- 所有操作都在你本机进行：读模拟器内存、读本地存档、起一个 localhost HTTP 服务
- 不收集任何数据，不上传任何信息
- "打开地图"按钮只是用浏览器打开公开网页 <https://botw.yalin.site>

## 要求

- Windows 10 / 11（64 位）
- Eden 模拟器 + Switch 版 BOTW
- 网页地图需要联网（https://botw.yalin.site）
