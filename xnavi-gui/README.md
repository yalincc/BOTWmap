# xnavi · 旷野之息实时定位导航

《塞尔达传说：旷野之息》（BOTW）实时定位工具，在网页地图上显示你在游戏里的位置，走路跟随。**v3.0.0 起三平台合一**：支持 **Cemu**、**Ryujinx**、**Eden** 三个模拟器。

网页地图：<https://botw.yalin.site>

## 功能

- **实时跟随**：只读模拟器内存，在网页地图上显示玩家坐标，随走路实时移动
- **骑乘跟随**：支持骑马、驾驶大师摩托车，自动捕获坐骑实体伴生定位，下马无缝切回
- **三平台**：Cemu（Wii U 版，大端）、Ryujinx（Switch 版，小端）、Eden（Yuzu fork，小端）自动识别
- **秒锁优先**：已知版本内存偏移直接定位，几秒钟出坐标；偏移失效时自动全内存结构扫描兜底
- **Eden 全距离定位**：Eden 采用全量结构扫描 + 占位池过滤 + 移动检测，玩家走离存档点也能定位（无需坐标校准）
- **18 项存档进度看板（v3.2.1 扩展）**：自动读游戏存档，显示探索 6 项（神庙/塔/神兽/克洛格/照片记忆/最终回忆）、任务 4 项、收集 5 项（宝箱/武器/图鉴×3）、讨伐 3 项，口径与网页探索度面板一致
- **自动开图（v3.2.1）**：定位成功后自动打开在线地图，并直接开启网页的「跟随玩家位置」
- **深色 GUI**：Wails 写的 Windows 桌面界面，状态一目了然
- **一键诊断**：出问题时点"导出诊断包"，把系统信息和日志打包发给开发者
- **只读内存**：不注入、不修改游戏、不联网上传任何数据

## 下载与使用

1. 从 [Releases](https://github.com/yalincc/BOTWmap/releases) 下载最新版：
   - `xnavi-v3.2.1.zip` —— 纯导航版，PC 浏览器打开在线地图
   - `xnavi-v3.2.1-BOTWmap-package.zip` —— 导航 + 离线地图整合包，支持手机局域网扫码导航
2. 解压到任意目录（路径不要有中文/空格更稳妥）
3. 先启动 Cemu / Ryujinx / Eden 之一，进入游戏（站在海拉鲁大地上，别开菜单）
4. 双击 `xnavi.exe`
5. 点 **▶ 开始定位**
6. 第一次定位可能需要在游戏里走两步（让程序确认坐标是活的）；按钮变绿「定位成功」时若开了自动开图，会直接打开网页地图并自动跟随
7. 在网页地图上就能看到自己的红点，跟着走就行

> Eden 无需配置路径（自动探测进程 + 存档）；Cemu/Ryujinx 可在设置里手动指定路径，不填也能自动探测。
> 首次运行 Windows 可能弹防火墙提示，点允许——它只在本机 `127.0.0.1:8766` 起 HTTP 服务给网页读坐标，不对外暴露。

## 手机镜像（APK）：手机看红点 + 屏幕常亮

手机和电脑连**同一 WiFi**，就能用手机看红点导航。推荐用随包附带的 `xnavi-mirror.apk`（仅 18KB），屏幕不会自动熄灭，比手机浏览器体验好得多。

**安装（每台手机一次）：**

1. APK 在压缩包的 `certs` 文件夹里（`xnavi-mirror.apk`）；
   也可以在电脑上运行 `certs\serve-cert.ps1`，手机浏览器打开它显示的地址，点 `xnavi-mirror.apk` 直接下载；
2. 手机上点开下载的 APK 安装。系统提示「禁止安装未知应用」时，按提示允许即可——本 APP 只申请网络权限，没有任何其他权限。

**使用：**

1. 电脑上点「开始定位」，界面会显示镜像链接（形如 `http://192.168.x.x:8766/botw/...`）；
2. 把链接复制发到手机（微信文件传输助手 / QQ 都行）；
3. 打开 **Xnavi Mirror**，粘贴链接（或只输 `电脑IP:8766`）→ 点「打开」。APP 会先检查电脑端是否在线：在线直接进入；连不上会明确提示原因；
4. 链接会记住，下次打开 APP 自动连接。
5. 返回键：网页后退 → 回到首页 → 再按一次退出。

**常见问题：**

- **提示连不上**：三查——电脑 xnavi 是否已启动、手机和电脑是否同一 WiFi、地址是否正确（IP 可能变化，以电脑上最新显示的为准）。
- **iPhone / iPad**：没有这个 APP（iOS 不允许这样安装）。替代方案：① 手机设置 → 显示与亮度 → 自动锁定 → 改为「永不」，用浏览器打开镜像链接即可；② 按 `certs` 目录内 README 的指引安装证书后用 https 链接访问。
- 用手机浏览器直接打开镜像链接也能用，但页面过几分钟会自动熄屏（浏览器安全限制）——这正是这个 APP 存在的意义。

## 存档相关（Q&A）

**Q: xnavi 怎么找到我的存档？**
A: 自动探测各平台存档目录：Cemu → `%APPDATA%\Cemu\mlc01\usr\save\00050000`（及常见便携目录）、Ryujinx → `%APPDATA%\Ryujinx\bis\user\save`、Eden → 运行中 eden.exe 同目录的 `user\nand\user\save` 与 `%APPDATA%\Eden\...`。找不到时在设置里手动填对应平台的存档路径（优先级：手动 > 自动）。

**Q: 日志提示 `no usable save anchor found - retrying` 是什么意思？**
A: 找不到可用存档。定位需要存档做锚点（"距存档点最近"判据）和进度同步，存档缺失时会一直重试。原因通常是：① 模拟器目录不常见（手动填存档路径解决）② 游戏还没保存过（进游戏后随便存一次档）③ 存档被移动/删除。修复版日志会列出每个尝试过的存档根，一眼看出缺什么。

**Q: 存档槽 0-5 加载哪个？**
A: xnavi 自动取**最近修改的槽**（mtime 最新）——BOTW 轮转写 6 个槽，最近写过的最接近当前状态。不同槽是不同时刻的存档（手动/自动存档，位置与进度可能不同），**不需要、也不建议手动指定**——用旧槽会导致进度看板显示旧进度。

**Q: 进度多久同步一次？**
A: xnavi 每 2 秒检查存档文件，**游戏保存后 ≤2 秒自动刷新**进度。红点（实时坐标）来自内存读取，不是存档，跟着走一直实时。

**Q: 红点是读存档还是读内存？**
A: 读内存（只读，不修改游戏）。存档只用于两件事：定位时的"距存档点最近"辅助判据 + 进度看板（神庙/塔/呀哈哈/回忆/神兽）。

**Q: 设置里的三个存档路径是干嘛的？**
A: Cemu / Ryujinx / Eden 各自的 BOTW 存档目录。留空 = 自动探测；填了 = 优先使用（解决自动探测不到的情况）。每个平台独立，互不影响。

## 常见问题

**Q: 点开始后一直"等待模拟器进程"？**
A: 确认模拟器已经启动并且游戏已经进到大地图（在主菜单里不行）。工具按进程名 `Cemu.exe` / `Ryujinx.exe` / `eden` 探测，别把模拟器改名。

**Q: 一直"扫描中"不出坐标？**
A: 在游戏里随便走几步，让程序确认坐标是活的。第一次扫需要 2-15 秒（Eden 全内存扫描约 2-3 秒）。

**Q: 网页地图看不到红点？**
A: 确认工具顶栏显示"坐标流同步中"，然后刷新网页 https://botw.yalin.site 。本地端口 8766 不能被别的程序占用（如果之前有残留 xnavi-core 进程，重启 xnavi 会自动清理）。

**Q: 多个模拟器都开着会怎样？**
A: 工具按 Auto 模式自动探测，建议只开一个。显式选择：模拟器下拉选 Cemu / Ryujinx / Eden。

**Q: 骑乘（马/大师摩托）时红点是否跟随？**
A: **v3.1.2 起已完全支持！** 林克骑马或开大师摩托车时，程序会自动感知骑乘状态并捕获坐骑实体伴生定位；下马或传送自动无缝切回林克本体，全程平滑跟随。

**Q: 这里的 18 项数字和网页上差几个？**
A: 探索 6 / 收集 5 / 讨伐 3 共 14 项两边一致（同一份存档、同一套标志位）。**任务 4 项**网页会把手动勾选的任务也算进去，所以网页可能略高。本面板只统计存档数据。

**Q: 进度数字不对？**
A: 工具自动读主存档（Ryujinx/Eden 取最近修改的槽，Cemu 取最近修改的槽）。如果你最近玩的是别的槽，进度会不对。

## 数据与隐私

- 所有操作都在你本机进行：读模拟器内存、读本地存档、起一个 localhost HTTP 服务
- 不收集任何数据，不上传任何信息
- "打开地图"按钮只是用浏览器打开公开网页 <https://botw.yalin.site/?follow=1&game=botw>（`follow=1` 表示"打开即跟随"）

## 要求

- Windows 10 / 11（64 位）
- Cemu（1.27+ 或 2.6 测试推荐）或 Ryujinx（任意 Canary 版）或 Eden（Yuzu fork）
- BOTW 游戏本体（Wii U 版或 Switch 版均可，1.6.0 测试）
- 网页地图需要联网（https://botw.yalin.site）
