========================================
  XNAVI v3.2.2 · 旷野之息实时定位导航
========================================

【这是什么】
电脑上的定位导航工具：读取模拟器内存，把游戏中林克的
实时位置显示在在线地图上（支持 Cemu / Ryujinx / Eden）。

【快速开始（电脑）】
1. 启动模拟器并进入游戏
2. 双击 xnavi.exe，点「开始定位」
3. 浏览器打开 https://botw.yalin.site 即可看到实时红点

【手机/平板跟随（需要两包组合）】
本导航包不含地图文件，手机映射需要配合地图包：
1. 到 GitHub Releases 下载地图包 botwmap-vX.Y.Z.zip
   （认准 botwmap-vX.Y.Z 前缀的那个）
2. 解压后把里面的 app 文件夹放进本目录
   （和 xnavi.exe 同目录，两个包合成一个即可）
3. 网页地图点右下角手机图标 → 二维码给手机扫码
   本目录自带 xnavi-mirror.apk，手机装它可防息屏

【常见问题】
· 点了定位没反应？——先确认模拟器已启动并进入游戏
· 地图不显示红点？——浏览器打开 http://127.0.0.1:8766/pos
  能看到一串代码 = 定位正常，问题在浏览器（多为代理工具）；
  看不到 = 定位服务没起来，在 GUI 日志里找 [server] 开头的行
· 详细教程与问答 —— 见 GUIDE.md（记事本/VSCode 均可打开）
· 问题速查 —— 见 TROUBLESHOOTING.md

【安全声明】
只读模拟器内存，不注入、不修改游戏、不联网上传任何数据。
