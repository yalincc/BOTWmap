# BOTWmap V1.6.7 版本报告（2026-10-19）

## 1. 版本概述
- **目标**：重构怪物层与营地图层接入官方缩放链体系（§12 口径），根治幽灵怪与图钉异常，联动世界档位与营地武器随档进阶；补齐 DLC2 任务怪独立开关，修复设置按钮 Toggle 体验缺陷。
- **最终结论**：**已正式发布**。经分阶段小步交付（P0~P5）与全量自动化门禁测试（164 passed, 0 failed 全绿），成功解决先前回档暴露的所有时序、DOM 结构与 loc 口径隐患，达到历史最强稳定性。

## 2. 发布内容
- **怪物层官方缩放体系（P0~P4）**：
  - 10 类小怪与 Dragon 换源官方缩放体系（tier-0~3.js + scaling.js），怪名与颜色根据玩家存档击杀积分动态改名改色（白银种随档缩放）；
  - 幽灵怪根治：台地/城堡西等处的 DLC2 任务怪被分流，默认 0 蜥蜴；
  - Boss 5 类（人马、独眼巨人、岩石巨人、莫尔德拉吉克、守护者）既有点位与历史讨伐绿勾（liveDone / #N 编号）100% 保护留存；
  - 「⚙️地图设置」中补齐 DLC2 任务怪独立开关（隐藏/显示），支持状态持久化与恢复默认复位。
- **世界档位计算与侧栏徽标（P3）**：
  - 依据存档 50 条计分怪击杀数动态推算世界积分（0~285=Lv1, 286~941=Lv2, 942~1555=Lv3, 1556+=Lv4）；
  - 侧栏存档区轻量金色徽标展示「世界档位: LvN (X分)」，鼠标悬停浮出官方阶梯提示，清空存档优雅归隐；移动小屏自适应防溢出。
- **营地层换源与武器随档进阶（P5）**：
  - 营地数据源切换为按档预计算的 `BOTW_TIER_CAMPS`（1416 营地 / 100 精选）；
  - 严格保持 `[[px, py]]` 嵌套数组口径，彻底消除营地图钉全灭历史隐患；
  - 武器 key 深度清洗，消除英文代码与 `+1` 残留；高级档位下营地武器动态升级（如三叉蜥蜴飞旋镖、兽神枪/兽神弓等）；
  - 莱尼尔卡片直读营地武器池，点击武器名平滑链入装备图鉴卡。
- **交互与体验优化**：
  - 右上角「⚙️设置」按钮支持 Toggle（展开/关闭双向切换）；
  - 设置「完成标记」新增讨伐 BOSS 隐藏开关。

## 3. 技术方案
- **数据管线**：`source/build_botwmap_tiers.py`（Python 标准库）基于 romfs `enemy-scaling.json`、`enemy-distribution.json` 离线预计算产出 `app/data/enemy-tiers/` 7 件数据件（tier-0~3.js, quest.js, hardmode.js, scaling.js）。
- **前端架构**：
  - `app/js/enemy-tiers.js`：负责 index 游标对齐混装 `composeMarkers` 与 `composeCamps`，通过 `EnemyTiers.apply()` 精准过滤小怪与注入混装标记，绝对不调用 `buildLayerList()` 破坏侧栏 DOM；
  - `app/js/camp.js`：实现 `CampLayer.reload(BOTW_TIER_CAMPS)`，深层重置索引，严格遵循 `c.loc` 嵌套数组口径，boot 尾部增加兜底调用解决时序竞争；
  - `app/js/save_upload.js`：解析 50 条计分怪哈希，积分推算联动侧栏徽标与图层重绘，严禁 try-catch 吞异常。

## 4. 踩坑与防御（攻克九坑复盘）
| 坑 | 根因 | 本版修复 | 长期教训 |
|---|---|---|---|
| 营地图钉全灭 | loc 字段拍平为 `[px,py]` 导致取点为 null | 严格保持 `[[px,py]]` 嵌套数组口径并在 verify 中加格式断言 | 数据结构对齐必须写自动化断言护栏 |
| 侧栏小怪行消失 | 换源时调用了 `buildLayerList()` 破坏 DOM | 改为仅重绘画布与更新索引，不重建 DOM | 图层列表与地图画布数据生命周期严格解耦 |
| 营地武器代码泄漏 | 原生 key 带 `-` 或 `+1` 词缀导致 DEX miss | 增加 `cleanWeaponKey()` 彻底清洗 | 武器字典反查必须经过前处理清洗层 |
| 初始化时序竞争 | camp boot 晚于 save_upload.init | 在 camp.js boot 尾部增加兜底 apply | 模块异步依赖必须双向容错 |
| 异常被吞排查困难 | save_upload 恢复段空 try-catch | 增加 console.error 显式报错 | 严禁空 try-catch 吞掉错误 |
