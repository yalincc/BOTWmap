# Xnavi 信标模组 — 安装与兼容

## 简介

让《旷野之息》游戏自身把林克的世界坐标写入一块内存信标，Xnavi 直接读取，
替代宿主侧的内存扫描。进神庙、传送、站桩等场景下定位稳定，无需手动操作，
不依赖 GDB、不暂停游戏。仅支持 **Eden 模拟器 + BOTW 1.6.0**（TitleID `01007EF00011E000`）。

## 安装

1. 把模组文件 `subsdk9` 放到 Eden 的模组目录：
   ```
   Eden/user/load/01007EF00011E000/Xnavi-Beacon/exefs/subsdk9
   ```
2. 在 Eden 的附加内容（Add-Ons）中启用该模组。
3. 使用含信标读取层的 Xnavi 核心（`xnavi-core.exe`）。

若同时装有 BOTW Optimizer，沿用它的 `main.npdm` 即可（本模组默认不带 npdm）；
单独使用本模组时，放入构建产物里的 `main.npdm`。

## 使用

在 Xnavi 设置里把"定位方式"选为 **模组注入（Eden 信标）**，开始定位后状态显示
`beacon` 即生效，红点随玩家移动。选择 **自动探测** 或不设置时，沿用原有的内存
扫描定位，兼容 Cemu / Ryujinx / Eden。

也可以直接编辑 `xnavi-gui-config.json`，加入 `"locateMode": "mod-inject"`；
或以 `xnavi-core.exe --emu=eden --locate=mod-inject` 启动核心。

信标缺失或停摆时自动回退到内存扫描，原有功能不受影响。

## 兼容性

- **BOTW Optimizer（UltraCam）**：本模组用 subsdk9，Optimizer 用 subsdk3，槽位不同，可共存。
- **UKMM 合并的 romfs 模组 / 金手指**：本模组只含 exefs，不改动 romfs 与代码补丁，无冲突。
- **游戏版本**：面向 1.6.0（main build ID `8E9978D50BDD20B4`）；其他版本坐标偏移可能不同。
- **重启**：模组随游戏自动加载，宿主自动重新定位信标，无需额外操作。

## 回滚

- 停用模组：把 `exefs/subsdk9` 改名（如 `subsdk9.disabled`）或删除整个模组文件夹，重启游戏。
- 定位方式切回"自动探测"即恢复内存扫描。

## 从源码构建

见 `plugin/README.md`（devkitA64 + exlaunch）。
宿主核心：`cd xnavi && go build -o xnavi-core.exe .`。

## 故障排查

- 状态不是 `beacon`：查 Eden 日志是否有 `XNAVI_BEACON started`；没有则模组未加载
  （检查 Add-Ons 是否启用、文件名是否为 `subsdk9`）。
- 坐标接近零：多见于标题画面（演员位于原点）；读档进入大世界后正常。
- 游戏卡在启动：确认未误放本模组的 `main.npdm`（与 Optimizer 冲突时沿用 Optimizer 的）。
- 日志大量 `Unmapped Read`：BOTW 在模拟器下的正常现象，非故障；可在 Eden 调整日志过滤。
