# CemuNavi · 《旷野之息》Cemu 实时定位导航（v1.3.2 应急复用版）

> ## ⚠️ 定位说明（2026-10-21 更新）
>
> 本程序 2026-10-07 起停止常规维护（主力版本为 xnavi，Cemu + Ryujinx + Eden 三合一）。
> **v1.3.2 是应急复用版**：为 xnavi 无法定位的用户提供 Cemu 备用方案，
> 并补齐了与 xnavi v3.1.0 同级的手机镜像导航能力（见下方 v1.3.2 更新）。
> 代码保留在仓库，仅应急维护。

为 Cemu（Wii U 模拟器）上的《旷野之息》提供实时位置导航与全自动进度同步的小工具。
只读 Cemu 进程内存，不注入、不修改任何游戏数据。

## v1.3.2 更新（手机镜像导航对齐 xnavi v3.1.0）

- **根路径直达镜像**：手机浏览器只输 `http://<电脑IP>:8766` 即自动跳转到跟随红点导航页；
- **HTTPS 双协议（可选）**：exe 旁 `certs/` 有证书（`server.pem` + `server.key`）自动启用，
  同端口 http + https 共存；手机镜像页走 https 后 **Screen Wake Lock 防息屏生效**（手机常亮）；
  证书生成见 `certs/README.md`（纯可选，不配完全不影响功能）；
- **缺图引导页**：exe 旁没有 `app/` 地图文件夹时，手机打开会看到内置引导页（告诉用户缺什么、怎么补），不再白屏；
- **exe 同目录 app/ 优先**：优先挂载 exe 同级 `app/` 地图（补齐地图后刷新页面即生效，无需重启）。

## 功能

- **秒锁定位**：遍历 Cemu 所有 ≥256MB 的 RW 私有块，试社区固定偏移
  `AllocationBase+0x1055300C`（备用 `+0xC1F8BF4`），启动即锁定，零扫描零走动。
- **不站定重扫**：锁到槽后一直读这个地址；连续 5 次读失败（过场/读图/进神庙）才重找。
  玩家站着不动是正常状态，不会误判死槽。
- **多实例自适应**：多个 cemu.exe 并存时自动挑能读到坐标的那个。
- **神庙内不漂移**：进入神庙内部坐标自动固定到入口，离开后恢复世界追踪。
- **网页地图**：本地服务 `127.0.0.1:8766` 把坐标实时同步到 https://botw.yalin.site/。
- **手机镜像导航**：手机/iPad 同一 WiFi 打开 `http://<电脑IP>:8766`，与电脑同一套地图
  （实时红点 + 目标导航 + 进度同步），网页地图二维码面板也显示该地址。
- **全自动进度同步**：自动解析 Cemu 存档（`mlc01/usr/save/00050000/*`，按 mtime 取最新槽），
  同步神庙 / 希卡塔 / 克洛格 / 回忆 / 神兽收集进度，游戏内保存后 ~1-2s 自动更新。

## 使用

1. 打开 Cemu 并进入《旷野之息》游戏
2. 双击 `start.bat`（或运行 `navicemu.exe`）
3. 电脑：地图自动打开，红点即玩家实时位置，探索度自动同步
4. 手机：同一 WiFi 打开 `http://<电脑IP>:8766`（控制台 LAN 行有完整地址）

地图地址：https://botw.yalin.site/
本地 API：http://127.0.0.1:8766/pos ・ /progress

## 兼容性

- 模拟器：Cemu 1.26 及以上（Windows）
- 游戏：《旷野之息》Wii U 版（日版 101c9300 + 中文补丁已验证）
