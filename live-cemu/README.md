# CemuNavi · 《旷野之息》Cemu 实时定位导航（v1.2.1）

为 Cemu（Wii U 模拟器）上的《旷野之息》提供实时位置导航与全自动进度同步的小工具。

## 功能

- **实时定位**：只读 Cemu 进程内存，获取玩家当前坐标（不注入、不修改任何游戏数据）
  - **确定性固定针位**（v1.2.0）：直接读社区固定偏移 `AllocationBase+0x1055300C`，启动即锁定、零扫描零走动（Cemu 2.x + JP v208 实测有效）
  - **神庙内不漂移**（v1.2.1）：走进/传送进神庙时内部小坐标不再被当真位置，红点固定神庙入口，离开后恢复
  - 已知位置秒连（免扫描）、社区链 / 结构扫描 + 坐标先验自动锁定（兜底）
  - 玩家站定不再误判死槽重扫；垃圾槽不再被当验证位对外服务
- **网页地图**：本地服务把坐标实时同步到在线地图，地图上显示玩家红点与移动轨迹
- **自动重连**：Cemu 或游戏重启后自动重新定位，无需手动干预
- **轨迹显示**：只展示位置与移动轨迹，不做内存写入
- **全自动进度同步**：自动解析 Cemu 存档（`mlc01/usr/save/00050000/*`），同步神庙 / 希卡塔 /
  克洛格 / 主线回忆 / 神兽收集进度到网页探索度，游戏内保存后 ~1-2s 自动更新，免手动上传
  - **进度真实值**（v1.2.1）：内嵌参考表清除历史存档状态残留（旧 done/entered/counts），/progress
    只输出当前存档真实完成数，不再携带旧快照污染

## 使用

1. 打开 Cemu 并进入《旷野之息》游戏
2. 双击 `start.bat`（或运行 `navicemu.exe`）
3. 地图自动打开，红点即玩家实时位置，探索度自动同步

命令行参数：

- `--no-open` 启动后不自动打开地图
- `--dump` 诊断模式：打印 Cemu 内存布局与定位结果
- `端口号`（如 `8766`）自定义本地服务端口，默认 8766

地图地址：https://botw.yalin.site/

## 兼容性

- 模拟器：Cemu 2.x（Windows）
- 游戏：《旷野之息》Wii U 版 v208（1.5.0）
