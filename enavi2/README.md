# Enavi2 —— Eden / 旷野之息 只读实时定位（AOB 锚定路线）

Enavi2 是独立于 `enavi` 和 `xnavi` 的定位项目，走 **AOB 锚定 + 固定偏移** 路线：

1. 从磁盘 NSO 选 main 独有特征码；
2. 在 Eden guest DRAM 的 ARM64 镜像里 AOB 锚定 main 基址（毫秒级）；
3. 实机 ptrscan 验证 `main_base + Δ` 固定链 → 跨会话秒定位。

目标：跨会话（重开 Eden）不变的「基址 + 固定偏移」，不再每次重扫。

> 为什么独立：`enavi` 持续测试未定位成功过一次（暂不通），`xnavi` Eden 分支机制复杂 bug 多。
> Enavi2 只复用两者**已验证的实测结论**（见开发计划 §3），不继承它们的代码路径和状态机。
