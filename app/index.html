使用帮助 · Q&A

📂 加载存档进度

存档文件：game_data.sav，拖进左侧面板或点「从存档加载进度…」即可，文件只在浏览器内解析，不会上传。

Ryujinx（Switch 模拟器）：

%APPDATA%\Ryujinx\bis\user\save\0000000000000008\0\1\game_data.sav

找不到时：按 Win + R，粘贴下面路径回车，进入游戏对应的 ID 目录找 game_data.sav：

%APPDATA%\Ryujinx\bis\user\save

Cemu（Wii U）：

mlc01\usr\save\00050000\101c9400\user\80000001\game_data.sav

🔄 进度是怎么同步的

上传存档后，浏览器本地解析出神庙 / 塔 / 克洛格 / 主线回忆 / 神兽的收集状态，写进本机浏览器，离线再打开也保留。

本机跑 live 服务（悬浮框导航）时，游戏内收集会自动同步，与上传共用同一套进度；手动勾选是叠加，不会冲突，以存档为准。

🧭 悬浮框与实时导航（本机）

运行 live/start-all.bat 一键启动服务和悬浮框；游戏里走动，浮窗与网页红点实时跟随。

点地图上的标注 →「导航」出现引导线；信息卡可拖住头部移动；状态胶囊：● 已连接 · ◐ 定位中（移动角色）· ● 离线。

回忆 / 克洛格标注的卡片里有「收集」按钮：开启后自动导航到离你最近的未收集点，收集完成（游戏内保存或手动勾选）自动前往下一个；底部横幅「结束」可随时退出。

❓ 常见问题

为什么宝箱 / 英杰·EX 回忆一直是 0？—— 这两类在存档里没有逐项记录，只能手动勾选。

克洛格计数器和实际数量不一致？—— 以游戏内实际收集为准（逐项记录），计数器仅供参考。

手机上能用吗？—— 能，上传存档即可；悬浮框导航仅限本机。
