使用帮助 · Q&A

📂 加载存档进度（网页上传）

存档文件：game_data.sav（Switch 与 Wii U·Cemu 同名，上传后自动识别端序），拖进左侧面板或点「从存档加载进度…」即可，文件只在浏览器内解析，不会上传。

常见存档位置：

Cemu：%APPDATA%\Cemu\mlc01\usr\save\00050000\101c9300\user\80000001\<槽>\game_data.sav
Ryujinx / Eden：%APPDATA%\Ryujinx\bis\user\save\...\01007EF00011E000\<槽>\game_data.sav

中间的用户/标题 ID 目录每个人不一样；找不到时按 Win + R 粘贴上面的根路径回车，逐层进到 game_data.sav 为止。101c9300 为日版（中文补丁一般基于日版 rom），美版 101c9400、欧版 101c9500。

🔄 进度是怎么同步的

上传存档后，浏览器本地解析出神庙 / 塔 / 克洛格 / 主线回忆 / 神兽的收集状态，写进本机浏览器，离线再打开也保留。

用 xnavi 实时定位时，进度自动同步：xnavi 每 2 秒检查你的存档文件，游戏保存后 ≤2 秒自动刷新，与上传共用同一套进度；手动勾选是叠加，不会冲突，以存档为准。

🧭 xnavi 实时定位（本机）

下载 xnavi 解压，先启动模拟器进游戏，双击 xnavi.exe → 开始定位。支持 Cemu / Ryujinx / Eden 三平台，自动识别，几秒锁定；游戏里走路/滑翔/传送，网页红点实时跟随。

存档自动探测；自动找不到时，在 xnavi 设置里手动填对应平台的 BOTW 存档路径即可。

回忆 / 克洛格标注的卡片里有「收集」按钮：开启后自动导航到离你最近的未收集点，收集完成（游戏内保存或手动勾选）自动前往下一个；底部横幅「结束」可随时退出。

📁 存档 Q&A（xnavi）

提示 "no usable save anchor found"？ 找不到可用存档（定位锚点 + 进度同步都需要它）。通常是：模拟器目录不常见 → 设置里手动填存档路径；游戏还没保存过 → 进游戏存一次档。

存档槽 0-5 加载哪个？ xnavi 自动取最近修改的槽（BOTW 轮转写 6 槽，最近写过的最接近当前状态）；不同槽是不同时刻的存档，不要手动指定旧槽，否则进度会显示旧数据。

红点是读存档还是内存？ 读内存（只读不修改游戏），存档只做定位辅助判据 + 进度来源。

❓ 常见问题

为什么宝箱 / 英杰·EX 回忆一直是 0？—— 这两类在存档里没有逐项记录，只能手动勾选。

克洛格计数器和实际数量不一致？—— 以游戏内实际收集为准（逐项记录），计数器仅供参考。

手机上能用吗？—— 能，上传存档即可；实时定位（红点跟随）仅限本机 xnavi。
