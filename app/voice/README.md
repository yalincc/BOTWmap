# BOTWmap 独立语音导航模块 (`app/voice/`)

本目录是 **BOTWmap（网页地图）** 专属的零耦合、可插拔实时语音导航模块（纯网页端收口，不内置于 `xnavi` 桌面定位端）。

## 目录结构

```text
app/voice/
├── voice-nav.js          ← 独立核心引擎（单一全局 Audio 实例，对外暴露 window.VoiceNav）
├── voice-config.json     ← 音色配置与 36 个标准导航词条定义表
├── zelda/                ← 离线语音包 A：塞尔达公主风（中文 36 个 48kbps 高清 .mp3）
├── yujie/                ← 离线语音包 B：御姐领航员（中文 36 个 48kbps 高清 .mp3）
├── en/                   ← 离线语音包 C：英式女声（英文 36 个 48kbps 高清 .mp3，英文界面自动启用）
└── README.md             ← 本说明文档
```

## 核心特性

- **单一全局 Audio 实例**：顺序播放本地高清 48kbps `.mp3`（一阶直出，零二次转码），物理杜绝并发重音；无自动系统 TTS 兜底。
- **罗盘 8 方位 + 真 3D 距离 + 海拔高低差**：严格对齐 BOTWmap 坐标系（`mx` 东正西负、`my` 北负南正，`1px = 0.5m`），结合 `marker_heights.js` 与 `xnavi` 实时海拔 `gy` 播报「目标在上方 / 下方」。
- **专属到达彩蛋**：支持神庙、克洛格、追花起点、树桩赛跑起点、宝箱、装备 6 类专属到达提示音。
- **独立语音设置卡 `#voiceBox`**：点击顶栏「🔊 语音」弹出，支持开关、2 档音色（塞尔达 / 御姐音）、音量 + 试听、高低差开关与 3 档播报频次（`100/25m`、`300/100/35m`、`500/300/100/50m`）。
- **重生成命令**：`python source/build_voice_packs.py`（依赖 `edge-tts`）。
